# Perform to Platform

This course is for developers with production COBOL experience who are learning Java and Spring Boot. You bring experience with business rules, production behavior, and change risk. The labs introduce the Java and application concepts needed to carry that experience into a new platform.

The examples use a fictional credit-request workflow. Its amounts, dates, status codes, and policies exist for practice; they are not a production credit policy.

## Start with the first lessons

Begin with these first two labs:

1. [Set up and trace a Java program](../modules/00-orientation/README.md). Build a JAR and follow an invoice number from command-line input to program output.
2. [Carry a business rule into Java](../modules/01-business-rules/README.md). Predict the existing status codes, restore the rule, and add an amount limit with boundary tests.

Use the checkout and JDK version provided by your instructor when you run the labs. The [glossary](glossary.md) defines terms where they appear. Instructors can use the [workstation preflight](instructor-preflight.md) to prepare the pilot.

## Continue through the course

The course site contains every lesson through the capstone. Use the [curriculum](../CURRICULUM.md#learning-sequence-and-material-status) to review the sequence and learning outcomes. Each lesson links to its source examples and its place in the sequence.

Use the matching course checkout and JDK version provided by your instructor to run and change the projects. The remaining course work is learner-pilot feedback and hands-on accessibility and workstation review.
